# 👔 Wardrobe AI

An AI-powered personal stylist that recommends outfits based on facial analysis, weather, occasions, and your personal wardrobe.

---

## 🚀 Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion

### Backend

- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT Authentication

### AI

- OpenCV
- MediaPipe
- Scikit-learn

### Deployment

- Render
- Vercel
- Docker
- GitHub Actions
